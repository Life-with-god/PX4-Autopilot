# LOCP 动力响应与失控保护方案（最终版）

> 状态：已实现（2026-08，随 cuav_7-nano 定制固件烧录）
> 依据：log_309 / log_311（7-31 卡防护网事故）、log_241 / log_285 / log_295（激进飞行）、近半年 327 个飞行日志
> 约束：测试场位于城市内，飞行高度 ≤ 10m，遥控器（RC）+ 地面站（QGC）双操控

---

## 一、目标场景与约束

| 项 | 说明 |
|---|---|
| **场景A 飞控发疯** | 控制环输出满油门，姿态/速度失控 |
| **场景B 动力无响应** | 高油门但运动响应不足（卡网 / 动力丢失 / 桨损坏 / 控制失效） |
| **失控乱飞** | 温和或剧烈：城市内温和乱飞同样危险，统一按失控处理 |
| 高度约束 | 飞行高度 ≤ 10m → 停桨坠落可控（自由落体 ≤1.4s）；≤5m 可考虑柔和降落 |
| 接管源 | 遥控器（RC）+ 地面站（QGC）双通道 |

设计原则：
1. 低空约束下，**停桨优先于降落**（降落对卡网无效、对发疯不可靠），但**低高度（≤5m）卡网可先试降落**（损伤更小）
2. **低阈值触发 + 接管安全阀**：温和乱飞也触发，靠"接管检查"防误报
3. 执行动作前**必须检查 RC + QGC 是否已接管**
4. **检测通用化**：检测"指标矛盾"（高油门 ↔ 响应不足 / 指令 ↔ 实际运动）
5. **统一状态机**：多路检测共用"失控确认"状态机，锁存防空窗

## 二、检测层

### 2.1 失控乱飞（温和/剧烈）—— 复用 ARD + VRD + PRD（低阈值）

| 维度 | 检测内容 | 参数（低阈值 + 持续性） | 状态 |
|---|---|---|---|
| ARD | 角速率持续超限 | 角速率 >2 rad/s 持续 0.2s（`LOCP_ARD_RSP/PSP=2`、`LOCP_ARD_DUR=0.2`）+ 角加速度 >100/120 rad/s²（`R_MAX/P_MAX`） | ✅ 已实现 |
| VRD | 水平速度持续异常 | 水平速度 >15 m/s 持续 3s（`LOCP_VRD_HS_MAX=15`、`LOCP_VRD_HS_DUR=3`） | ✅ 已实现 |
| PRD | 漂移/急降 | 持续远离 / 高度急变 | 保持原有 |
| 校准上限 | Position/Offboard | ARD_R_MAX=100、ARD_P_MAX=120、VRD_AH_MAX=55 | ✅ 已实现 |

**日志标定依据**（Position/Offboard 模式，无特技）：
- 角速率 >2 rad/s：正常日志（143 个）连续超阈值最长仅 **0.02s**（P99≤1.17 rad/s）；异常日志（卡网/失控）连续 0.12~0.70s → 持续阈值取 0.2s（配合 0.1s 角加速度迟滞，抓 0.25s+ 异常）
- 角加速度：正常日志无持续段（单帧峰值 P99=156）；失控峰值 472~855 rad/s² → 阈值取 100/120 rad/s²
- 水平速度 >15 m/s：本机理论最大速度 10 m/s（1.5 倍裕度），正常飞行满速也不触发；EGO 视觉故障（08_29_39 及 7-8 月 11 份同源日志）速度 18~106 m/s 持续 **3~330s** → 取 15 m/s 持续 3s，全部仍能检测
- 卡网场景水平速度较低（log_311 最大 3.9 m/s < 15），由 TRD 动力响应校验兜底

### 2.2 动力无响应（卡网/动力丢失）—— 新增"动力响应校验"

```
油门指令高（T > LOCP_TRD_THR_H = 0.85）
 持续 ≥ LOCP_TRD_T = 3.0 秒
 + 实际垂直加速度 az < LOCP_TRD_AZ_MIN = 5 m/s²（该加速却没加速）
→ 判定"高油门无响应" → 动力异常
```

**注意**：az 必须用 EKF 去重力后的运动加速度（`vehicle_local_position.az`），不能用加速度计原始读数（被卡时加速度计仍读 1g）。

**覆盖**：卡网（顶部/侧边）、动力丢失、桨损坏、控制失效。

**log_309 回放**：卡网段（7~33s）油门 1.0、az≈0 → 第 10s 触发。

## 三、动作层（<10m 约束，含分级动作）

### 3.1 动力无响应 → **分级动作**（新）

```
动力无响应检测触发（高油门 + az 不足）
        │
        ▼
【高度判定】
 ├─ 高度 ≤ 5m（低空）→ 尝试柔和降落（减油门）
 │        ├─ 3~5s 内飞机响应下降 → 继续降落（成功）
 │        └─ 3~5s 仍不动（被网吊住）→ 转停桨 Disarm（兜底）
 │
 └─ 高度 > 5m 或 已被抛飞 → 直接停桨 Disarm
```

**验证**：
- log_309（2.4m 顶网）→ 先试降落 → 成功柔和落地 ✅
- log_311（8.8m 抛飞）→ 直接停桨 ✅
- 被网吊住降不下来 → 3~5s 超时转停桨（兜底）✅

**注意**：降落尝试期间若出现"飞机被网吊住 + 飞控反复顶油"，必须靠超时强制转停桨，防止电机过载。

### 3.2 失控乱飞（温和/剧烈）→ Disarm

低阈值触发 + 接管检查（见下），无接管或接管无效 → Disarm。

### 3.3 动作汇总

| 场景 | 动作 | 条件 |
|---|---|---|
| 动力无响应 + 高度 ≤5m | **先试降落** → 超时转 Disarm | 柔和优先 |
| 动力无响应 + 高度 >5m / 抛飞 | **Disarm** | 直接停桨 |
| 失控乱飞（温和/剧烈） | **Disarm** | 城市环境快速处置 |
| 接管成功 | 放行 | 运动恢复正常 |

## 四、接管检查（执行动作前）—— RC + QGC 双通道

```
检测触发（乱飞 / 动力无响应）
        │
        ▼
【接管源检查：遥控器（RC）+ 地面站（QGC）】
        │
 ├─ RC 失联 且 QGC 无指令/未连接 → 立即 Disarm（双通道失效）
 │
 ├─ 用户有 RC 输入 或 QGC 有指令 → 观察 2~3s：
 │        ├─ 恢复 → 放行（接管成功）
 │        └─ 仍乱/无响应 → Disarm（接管无效 = 真失控）
 │
 └─ 两者都无输入 → Disarm（快速处置）
```

**注意**：降落尝试（3.1）也受接管检查约束——若用户在降落尝试期间接管，让位给用户。

### 接管源判定

| 接管源 | 数据源 | 判定 |
|---|---|---|
| 遥控器 RC | `manual_control_setpoint` / `input_rc` | 摇杆有效输入 |
| RC 失联 | `vehicle_status.rc_signal_lost` | 用户无法干预 |
| QGC 地面站 | `vehicle_command`（来源=GCS） | 最近 1~2s 有指令 |
| QGC 连接 | `telemetry_status` | 地面站在线 |

## 五、统一状态机（时间逻辑）

多路检测（乱飞、动力无响应）共用同一"失控确认"状态机，**锁存**防空窗：

```
┌─────────┐  任一检测触发  ┌──────────────┐
│  正常飞行 │ ───────────> │ 异常确认中(去抖) │
└─────────┘               └──────┬───────┘
     ▲ 连续正常 3s(复位)          │ 持续 T_confirm (2~3s)
     │                            ▼
     └─────────────────── ┌──────────────┐
         (未 Disarm 前)    │ 接管检查+观察  │
                          │ (RC+QGC, 2~3s) │
                          └──────┬───────┘
                                 │ 分级动作（降落尝试/Disarm）
                                 ▼
                           ┌──────────────┐
                           │ 动作执行(终态) │
                           └──────────────┘
```

**时间参数**：

| 参数 | 值 | 说明 |
|---|---|---|
| T_confirm（异常确认去抖） | 2~3s | 乱飞持续 / 动力无响应持续 |
| T_takeover（接管观察） | 2~3s | RC/QGC 接管窗口 |
| T_land_try（降落尝试超时） | 3~5s | 被网吊住时强制转停桨 |
| T_reset（复位要求） | 3s | 连续正常才复位 |
| T_total（最坏响应） | ~5-8s | 从异常到动作，<10m 可接受 |

**锁存设计**：一旦进入"异常确认"，不因单帧恢复正常而复位（避免撞网瞬间乱飞检测复位造成空窗）；仅当"连续正常 3s"才回正常。

## 六、参数清单

### 6.0 使能开关（默认禁用）

> **重要**：所有 LOCP 使能开关**默认 =0（禁用）**，刷机后 LOCP 不运行。
> 启用流程：在 QGC 中依次开启 `LOCP_EN`（总开关）→ 所需维度 `*_EN` → 所需子检测 `*_EN`。

| 层级 | 开关 | 默认 |
|---|---|---|
| 总开关 | `LOCP_EN` | 0（禁用） |
| 维度 | `LOCP_ARD_EN` / `VRD` / `PRD` / `COD` / `MTO` / `OBS` / `TRD` / `CRASH` | 全部 0 |
| 子检测 | `ARD_ACC`/`ARD_RATE`、`VRD_AH`/`FF`/`JK`/`HS`、`PRD_DES`/`OSC`/`DRF`、`COD_SRG`/`SPK`、`MTO_HB`/`CMD`、`OBS_JMP`/`NAN` | 全部 0 |

### 6.1 新增参数（动力响应校验 + 分级动作）

| 参数 | 默认 | 含义 |
|---|---|---|
| `LOCP_TRD_THR_H` | 0.85 | 高油门判定阈值 |
| `LOCP_TRD_T` | 3.0 | 高油门持续秒数 |
| `LOCP_TRD_AZ_MIN` | 5.0 | 垂直加速度下限 (m/s²) |
| `LOCP_TRD_LAND_H` | 5.0 | 降落尝试高度阈值 (m)，≤此值先试降落 |
| `LOCP_TRD_LTOUT` | 4.0 | 降落尝试超时 (s)，超时转停桨 |
| `LOCP_TRD_WATCH` | 3.0 | 接管观察窗口 (s)，接管无效 → 强制停桨 |

### 6.2 校准参数（乱飞检测）

| 参数 | 原默认 | 校准值 | 依据 |
|---|---|---|---|
| `LOCP_ARD_R_MAX` | 80 | 100 | 正常无持续段（单帧P99=156），失控 472~855 |
| `LOCP_ARD_P_MAX` | 80 | 120 | 同上，失控 276~855 |
| `LOCP_VRD_AH_MAX` | 8 | 55 | log_295 实测 36.5 m/s² |
| `LOCP_ARD_RSP/PSP` | 6 | 2 | 正常连续>2 最长 0.02s，异常 0.12~0.70s |
| `LOCP_ARD_DUR` | 0.3 | 0.2 | 与 RSP/PSP=2 配合，抓 0.25s+ 异常 |
| `LOCP_ARD_T` | 0.3 | 0.1 | 2026-08-13 复测（排除地面翻倒失控样本）：正常飞行连续超阈段最长 0.042s，事故 log_309 0.221s → 取 0.1s |
| `LOCP_VRD_HS_MAX` | -（新增） | 15 | 本机理论最大 10 m/s（1.5 倍裕度）；EGO 故障 18~106 持续 |
| `LOCP_VRD_HS_DUR` | -（新增） | 3.0 | 与 15 m/s 配合，EGO 故障 3~330s |
| `LOCP_TRD_WATCH` | -（新增） | 3.0 | 方案 T_takeover=2~3s |

### 6.3 动作配置

| 项 | 建议 |
|---|---|
| 失控乱飞 | Disarm（独立通道，允许接管） |
| 动力无响应 ≤5m | Land（柔和）→ 超时 Disarm |
| 动力无响应 >5m | Disarm |
| RC 失联且 QGC 无指令 | 跳过接管逻辑，立即 Disarm |
